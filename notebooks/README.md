# notebooks

`reproduce_results.ipynb` recomputes every reported result from the stored outputs, checks the recomputed files
against the released ones, redraws the data figures and recomputes the references from the supply network. It runs on
[Colab](https://colab.research.google.com/github/sara-almahri/supply-chain-disruption-monitoring/blob/main/notebooks/reproduce_results.ipynb)
without an API key or Neo4j instance.
